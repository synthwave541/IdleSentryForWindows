## Installation and updates

Requires Windows 10 build 19041 or later, or Windows 11. Choose `win-x64-Setup.exe` for Intel/AMD or `win-arm64-Setup.exe` for Windows on ARM. Standalone installers are unsigned and may trigger SmartScreen. Setup installs for your user; preferences remain separate from the installation.

Existing standalone installations continue to check this repository for updates through About. Both architecture feeds and the Zennoris.IdleSentry package identity are unchanged. `.nupkg` files and JSON feeds are updater assets, not manual installers. Microsoft Store installations remain a separate channel updated by Microsoft Store: https://apps.microsoft.com/detail/9nfl78zt5kbc .
